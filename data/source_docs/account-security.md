# Account Security

Accounts support password authentication, single sign-on on eligible plans, and multi-factor authentication. Time-based one-time password applications can be enabled from Settings > Security.

After five consecutive failed password attempts, password login for the account is locked for 15 minutes. A successful login resets the failed-attempt counter.

Recovery codes are shown when multi-factor authentication is enabled. Each recovery code can be used once. Users should store recovery codes outside the device used for their authenticator application.

Active sessions can be reviewed and revoked from the Security page. Changing the account password revokes other active password-based sessions.
