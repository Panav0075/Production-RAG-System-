# Data Retention

Data retention depends on the type of data and workspace plan. Deleted project records remain recoverable for 30 days before permanent deletion.

Audit log history is retained for 30 days on Free workspaces, 180 days on Pro workspaces, and 365 days by default on Enterprise workspaces. Enterprise customers can request a custom audit-log retention period.

Uploaded files follow the retention policy of the project that owns them. When a project is permanently deleted, associated files are queued for deletion. Backups may persist for up to 14 additional days before they expire from the backup system.

Workspace administrators can export audit events before the retention window expires.
